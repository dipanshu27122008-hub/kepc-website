# API & Interface Contracts (`docs/api/`)

## Purpose
This directory stores interface specifications, contract definitions, and schemas for the project.

## Conventions
- For REST/HTTP APIs: Place OpenAPI/Swagger specs (`openapi.yaml` or `openapi.json`).
- For RPC services: Place Protocol Buffer definitions (`.proto`) or schema files.
- For GraphQL: Place schema definitions (`schema.graphql`).
- For CLI/Libraries: Document command signatures, flags, and public programmatic interfaces.
